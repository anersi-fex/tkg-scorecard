## Gotchas
- `scripts/local-db/start.sh` ends with a check that the anon key is refused on `agents`; the migration revokes grants from `anon`/`authenticated` so that check (and the real Supabase keys) get an error, not an empty list.
- The React Compiler lint rules are strict: no `Date.now()` in render (freshness is computed on tap in `sale-row-menu.tsx`), no setState in an effect body (the celebration queue lives in refs, `showNext` chains timeouts).
- `PageProps<"/log">` etc. are generated types: run `npx next typegen` after adding a route.
- Playwright in the sandbox is global: `scripts/smoke.mjs` loads it through `createRequire` (or `PLAYWRIGHT_DIR`).
- Lineage (2026-11-12). Every sales read that joins the person writes `agents!agent_id(name)`: a bare `agents(name)` turns ambiguous the day `sales.logged_by_agent` is made a real link (0005 keeps it a plain column so the app that was live during the migration kept reading). Ids in actions are checked with `z.guid()`, not `z.uuid()` (zod 4's `uuid()` wants an RFC version and refused the hand-made ids of a seed). The sign-in throttle also lives in the server's memory for 15 minutes: deleting `login_attempts` rows does not unlock an address in a running server, and a right team password or personal sign-in no longer clears an address's wrong tries (keep a test under 10 wrong tries per address). Once anyone has a personal sign-in, plain `/login` opens on the personal form: a script that types only a password opens `/login?way=team`. The People page makes the agency join link the first time a manager opens it (`getJoinLink()` while rendering). On a phone the tab bar hides while a text box has focus and comes back 60 ms after; in phone emulation, submit a form near the bottom edge with Enter. The TV celebrates only a sale logged after the newest one the open page knows, and a fixed sale, a goal or a change to a person reaches it at its next full read (within a minute), not within 5 s.
